# __SET_ME__ is deliberately not a number. From laue-index 0.7.2 the Python

# pipeline/dispatch/preflight.sh and pipeline/dispatch/mkrun.py also refuse a file
# that still contains one, before anything is launched.
#
# Units: lengths in metres (P_Array, PxX, PxY), lattice edges in nm, lattice
# angles, OrientationSpacing and MaxAngle in degrees, energies in keV.
# R_Array is a ROTATION VECTOR (axis x angle) with the angle in RADIANS -- not
# degrees, and not a Rodrigues-Frank vector (axis x tan(angle/2)).
# =============================================================================
